Meta Tags ka Khandaan

Baccho wali Hindi me, bilkul easy

1. Meta Tags hote kya hain?

Meta Tags = Website ka Visiting Card

Ye tags user ko direct nahi dikhte. Ye sirf Google aur Browser ko batate hain ki "ye website kis baare me hai".

Ye sab <head> tag ke andar likhe jate hain.

2. Sabse Important Meta Tags

A. <meta charset="UTF-8">

Kaam: Browser ko batata hai ki Hindi, Emoji, ₹ sab support karega.

<meta charset="UTF-8">

B. <meta name="viewport">

Kaam: Phone me website sahi size me khule. Zoom out na ho.

Nahi lagaya to: Website desktop wali hi choti dikhegi mobile me

<meta name="viewport" content="width=device-width, initial-scale=1.0">

C. <title> Tag

Kaam: Browser tab me jo naam dikhta hai. Google me bhi neele rang ka link yahi hota hai.

SEO Rule: 60 characters se kam rakho. Main keyword pehle likho

<title>Data Analyst Course 2026 | Free in Hindi</title>

D. <meta name="description">

Kaam: Google me title ke neeche jo 2 line dikhti hai wahi hai. Ye SEO ka King hai.

SEO Rule: 150-160 characters. User ko click karne ka mann kare aisa likho

<meta name="description" content="Learn Data Analyst in 10 weeks. Excel, SQL, Python with 3 projects.">

E. Social Media Meta Tags - OG Tags

Kaam: Jab link WhatsApp/FB pe share karte ho to jo photo + title dikhta hai wo yehi hai

<meta property="og:title" content="10 Week Data Analyst Roadmap">
<meta property="og:image" content="banner.jpg">

3. Meta Tags SEO me kaise Help karti hain?

SEO = Google me apni website ko upar lana

Meta Tag SEO me fayda Simple me
Title Tag Sabse bada ranking factor Google ko batata hai page kis keyword pe hai
Description CTR badhata hai Achi description = zyada click = Google rank up
Viewport Mobile Friendly Score Google mobile wali site ko upar rakhta hai

Ek line me: Meta tags Google ko "context" deti hain. Google andha hai. Tum hi batana padega ki page kis baare me hai.

4. Bhai ki 3 Golden Rules

  • Rule 1: Har page ka Title aur Description alag hona chahiye. Copy paste mat karna
  • Rule 2: Keyword stuffing mat karo: data, data, data aise likhne se Google ban karega
  • Rule 3: Mobile First socho: viewport tag har website me pehle din lagana hai
