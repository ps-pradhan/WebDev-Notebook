🎬 EPISODE 01: WEB DEVELOPMENT KI SHURUAT

⚠️ Pro Tip: Ye series ratne ke liye nahi hai. Har scene ko samjho aur code khud likho. Tabhi yaad rahega. Chalo shuru karte hain!

SCENE 1: CLIENT, BROWSER & SERVER

Website kaise chalti hai ye samajhna sabse zaruri hai. Jab tum Google pe click karte ho, tum Client ho. Google ka computer Server hai. Aur beech me Browser tumhara dost hai jo baat karwata hai.

SCENE 2: VS CODE INSTALL KAISE KAREIN

  1. Koi bhi text editor chalega, par hum VS Code use karenge.
  2. Kyunki ye free hai, halka hai, aur Microsoft ka hai.
  3. Google pe jao, "VS Code" search karo aur install kar lo

Note: Tum HTML Notepad me bhi likh sakte ho. VS Code se kaam 10x easy ho jata hai bas.

SCENE 3: HTML HOTA KYA HAI?

HTML = Hyper Text Markup Language

  • HTML website banane ki bhasha hai. Isse hum websites ka skeleton banate hain
  • Hum HTML tags ka use karke website ka structure banate hain
  • In tags ko jod kar hum sundar websites bana sakte hain!

SCENE 4: TOH CSS AUR JAVASCRIPT KI KYA ZARURAT?

Ek website banane ke liye 3 cheezein chahiye hoti hain:

  1. HTML - Page ka skeleton / Haddi
  2. CSS - Skeleton ko sundar banata hai / Kapde aur makeup
  3. JavaScript - Page me jaan dalta hai / Button click pe kaam

🎉 SAABASH! EPISODE 1 CLEAR 🎉

Level Up: Ab tumhe pata hai website ka engine kaise chalta hai.
HTML = Haddi, CSS = Kapde, JS = Dimaag. Foundation pakka ho gaya 💪
