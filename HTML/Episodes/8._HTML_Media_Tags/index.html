SCENE 1: <video> Tag 🎥

Concept: Website me video chalane ke liye. HTML5 ka apna player mil jata hai.

Important Attributes:

  • src = video file ka path
  • controls = play, pause, volume ka button
  • width height = video ka size
  • autoplay = page load hote hi video chalu
  • loop = video khatam hote hi dobara chalu
  • muted = bina sound ke chalu
  • poster = video chalne se pehle thumbnail dikhane ke liye

Code Example:

<video 
  src="video.mp4" 
  controls 
  width="400" 
  height="200"
  poster="./thumbnail.png">
</video>

SCENE 2: <audio> Tag 🎵

Concept: Website me gaana ya koi sound play karne ke liye.

Important Attributes:

  • src = audio file ka path
  • controls = play, pause, volume ka button
  • autoplay = khud chalu
  • loop = repeat

Code Example:

<audio src="audio.mp3" controls></audio>

Output:

🔥 Interview Question: `preload` kya hai?

Ye batata hai page load hote time audio kitna load karna hai:

  • preload="none" = Kuch mat load karo. User click kare tabhi load hoga. Data bachega.
  • preload="metadata" = Sirf duration aur info load karo. Fast hota hai.
  • preload="auto" = Pura audio background me load karo. Turant play hoga.

SCENE 3: SVG in HTML 🎨

Concept: SVG = Scalable Vector Graphics. Iska fayda ye hai ki kitna bhi zoom karo, quality kharab nahi hoti.

Logo aur Icon banane ke liye best hai.

Method 1: Inline SVG | Code me hi likh do

<svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="#000" stroke-width="3" fill="red" />
</svg>

Output:

Ye circle Inline SVG se bana hai

Method 2: IMG Tag se | Alag file se

<img src="logo.svg" alt="Logo">

Important Interview Note: Agar tum `logo.svg` alag file bana rahe ho, toh uss file main aapko aisha likhna hoga: 


      <svg xmlns="http://www.w3.org/2000/svg" width="100" height="100">
        <circle cx="50" cy="50" r="40" stroke="#000" stroke-width="3" fill="red" />
      </svg>

Warna browser me error aa sakta hai.

SCENE 4: <iframe> Tag 🖼️

Concept: Ek website ke andar dusri website dikhane ke liye. Jaise YouTube Video, Google Map.

Important Attributes:

  • src = jis page ko embed karna hai uska link
  • width height = size
  • frameborder = border hatane ke liye 0 kar do
  • allowfullscreen = full screen karne ki permission

Code Example:

<iframe 
  width="900" 
  height="615" 
  src="https://www.youtube.com/embed/XZwBNDGuWGU?si=9DFkSwOuCI_okYFM&start=685" 
  title="YouTube video player" 
  frameborder="0" 
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" 
  referrerpolicy="strict-origin-when-cross-origin" 
  allowfullscreen>
</iframe>
