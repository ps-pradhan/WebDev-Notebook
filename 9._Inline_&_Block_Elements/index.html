Block vs Inline Elements - Detailed Notes

Note: Ham abhi sirf Inline CSS use kar rahe hai taki color se difference samajh aaye. Future me External Stylesheet seekhenge.

PART 1: BLOCK ELEMENTS

Block ke 3 Funde:

  • 1. Hamesha nayi line se shuru hote hain
  • 2. Puri width lete hain
  • 3. Width, Height, Margin, Padding sab lagta hai

1. <div> - Generic Container

Funda: Sabse common block. Iske andar hum poora section banaate hain. Iska koi matlab nahi hota, sirf box banane ke liye.

Code:
<div style="background-color: lightgreen; padding: 10px;">Main ek Div hun</div>
Main ek Div hun

2. <p> - Paragraph

Funda: Text likhne ke liye. Browser khud upar-neeche thoda gap de deta hai.

Code:
<p style="background-color: pink;">Ye pehla paragraph hai</p>
<p style="background-color: pink;">Ye dusra paragraph hai</p>

Ye pehla paragraph hai

Ye dusra paragraph hai - Dekho gap aa gaya

3. <h1> to <h6> - Headings

Funda: Heading dene ke liye. h1 sabse bada, h6 sabse chhota. SEO ke liye important.

Code:
<h1 style="background-color: yellow;">Main H1 hun</h1>
<h3 style="background-color: yellow;">Main H3 hun</h3>

Main H1 hun

Main H3 hun

4. <ul> & <li> - List

Funda: List banane ke liye. ul = bullet, ol = 1,2,3. li = list ka item

Code:
<ul style="background-color: lightblue;">
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
  • Item 1
  • Item 2

5. <form> - Form

Funda: User se data lene ke liye. Input, Button sab iske andar aate hain.

Code:
<form style="background-color: #f0f0f0; padding: 10px;">
  <input type="text" placeholder="Name">
  <button>Submit</button>
</form>

Note: header, footer, section, article, table bhi block hain. Ye hum aage detail me seekhenge

PART 2: INLINE ELEMENTS

Inline ke 3 Funde:

  • 1. Nayi line nahi lete, bagal me chipak jaate hain
  • 2. Sirf content jitni width lete hain
  • 3. Width, Height nahi lagta. Sirf Left-Right margin/padding lagta hai

1. <span> - Generic Inline Container

Funda: Inline ka div. Text ke kisi chhote hisse ko style karne ke liye.

Code:
Ye text <span style="background-color: yellow;">yellow</span> hai
Ye text yellow hai

2. <a> - Anchor / Link

Funda: Ek page se dusre page par le jata hai. Sabse important inline tag.

Code:
<a href="#" style="background-color: lightblue; padding: 5px;">Click Me</a>
Click Me

3. <img> - Image

Funda: Image dikhane ke liye. Ajeeb baat: ye inline hai par isko width/height lagti hai

Code:
<img src="https://via.placeholder.com/100" alt="Demo">

4. <strong> & <em> - Bold & Italic

Funda: strong = important text, bold. em = stressed text, italic. SEO ke liye strong/em use karo, b/i mat karo

Code:
Ye <strong>important</strong> aur ye <em>emphasis</em> hai
Ye important aur ye emphasis hai

5. <input> & <label> - Form Elements

Funda: User se input lene ke liye. label batata hai ki input kis cheez ka hai

Code:
<label>Name:</label> <input type="text">

Note: button, br, small, sub, sup bhi inline hain. Ye hum aage use karte time seekhenge
