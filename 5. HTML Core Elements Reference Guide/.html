Forms in HTML - Zero se Hero

Form kya hota hai? Socho tum dukaan me gaye. Dukaandaar tumse naam, number, address maangta hai. Website bhi wahi kaam karti hai. Form ke through wo tumse data maangti hai.

1. Basic Structure of Form

Saara khel <form> tag ke andar hota hai. Ye ek dabba banata hai jisme saare sawal hote hain. 


<form action="/action.php" method="post">
    <!-- form content -->
</form>

Samjho:
action="/action.php" = Form bharne ke baad data is file me jayega. Jaise chithi postbox me jaati hai
method="post" = Data chhup ke jayega. Password ke liye yehi use karte hain. `get` me data URL me dikh jata hai

2. Input Tag - Form ka Dil

Form me jo bhi box, button dikhta hai wo sab <input> se banta hai. Iska roop `type` se badalta hai.

a. Common Attributes - Har Input ke liye

<label for="name">Naam:</label>
<input type="text" name="username" id="name" placeholder="Apna naam likho" required>

Samjho ek ek karke:
type="text" = Normal likhne wala box
name="username" = Sabse zaroori. Jab form submit hoga to server isi naam se data pehchanega. Bina name ke data waste hai
id="name" = Label ko is box se jodne ke liye
placeholder="Apna naam likho" = Halka text jo hint deta hai. Jaise hi likhoge gayab ho jayega
required = Teacher jaisa. Khali chhodoge to form submit hi nahi hone dega

Samjho:
password = Jo likho wo ***** ban jata hai
email = Galat email likhoge to browser khud bolega "galat hai"
number = Sirf number aur upar-neeche ke teer aayenge
date = Calendar khul jayega
file = Computer se file choose karne ka button
submit = Form bhejne wala button. `value` me button par kya likhna hai wo likhte hain
reset = Sab saaf karne wala button

c. Choice Wale - Radio aur Checkbox

Radio = MCQ jisme 1 hi answer. Sabka `name` same rakhna hai

Ling: 

<input type="radio" name="gender" id="m" value="male">
<label for="m">Ladka</label>
<input type="radio" name="gender" id="f" value="female">
<label for="f">Ladki</label>

Checkbox = MCQ jisme kitne bhi answer tick kar sakte ho

Subject: 

<input type="checkbox" name="sub" id="math" value="math">
<label for="math">Maths</label>
<input type="checkbox" name="sub" id="sci" value="science">
<label for="sci">Science</label>

value = Ye server ko jata hai. User ko nahi dikhta. Jaise `value="male"` server tak "male" shabd pahunchayega

3. Label Tag - Dosti wala Tag

Label ka kaam hai input ko naam dena. Aur fayda ye ki label par click karoge to bhi box select ho jayega.

<label for="email">Email ID:</label>
<input type="email" id="email">

Rule: `label for` = `input id`. Dono same hone chahiye. Isse blind logon ki help hoti hai.

4. Select Tag - Dropdown List

Jab 50 state ho to 50 radio button nahi banayenge. Dropdown banate hain.

<form action="/action.php">
  <label>Sheher chuno:</label>
  <select name="city">
     <option value="delhi">Delhi</option>
     <option value="mumbai">Mumbai</option>
     <option value="hyd">Hyderabad</option>
  </select>
</form>

5. Textarea Tag - Bada Box

Address, Feedback, Story likhne ke liye. Kitni bhi line likh sakte ho.

<label>Feedback:</label>
<textarea name="msg" rows="4" cols="40" placeholder="Yaha likho..."></textarea>

rows = Kitni line unchi
cols = Kitni line chaudi

6. Advanced HTML5 Validation - Bina JS ke Check

Browser khud check kar lega ki data sahi hai ya nahi.

<input type="text" pattern="[0-9]{10}" placeholder="10 digit number" required>

Samjho:
required = Khali nahi chhod sakte
pattern="[0-9]{10}" = Sirf 10 number chalenge. Letter daaloge to error
autofocus = Page khulte hi cursor yaha aa jayega
