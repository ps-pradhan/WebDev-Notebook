Episode 07: ID aur CLASS in HTML

ID

Page me sirf 1 unique element ke liye. CSS me # se likhte hain. 1 baar hi use hogi.

HTML

<button id="alert-btn">Delete</button>

CSS

#alert-btn {
  background: #da3633;
  font-weight: bold;
}

OUTPUT

CLASS

Ek jaisi styling wale multiple elements ke liye. CSS me . se likhte hain. Kitni bhi baar use kar sakte.

HTML

<button class="btn">Save</button>
<button class="btn">Update</button>

CSS

.btn {
  background: #1f6feb;
  padding: 10px 20px;
}

OUTPUT

Quick Summary

ID #name | Single use | JS/Link/Unique ke liye
CLASS .name | Multiple use | Styling ke liye
Priority ID > CLASS. Dono takraye toh ID jeetegi
