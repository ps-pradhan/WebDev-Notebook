HTML Media Tags

1. <video> Tag

Website me video embed karne ke liye. Apna player mil jata hai.

<video src="video.mp4" controls width="400" height="225"></video>

src = video ka path
controls = play/pause button
width / height = video ka size set karne ke liye.
autoplay = khud chalu
loop = repeat
muted = bina sound
poster = video se pehle thumbnail

OUTPUT

2. <audio> Tag

Website me audio/gaana play karne ke liye.

<audio src="audio.mp3" controls></audio>

controls = play/pause/volume
autoplay = khud chalu
loop = repeat

Interview Q: preload kya hai?

Ye batata hai page load hote time audio kitna load karna hai.
1. preload="none" = Kuch mat load karo. User click kare tabhi load hoga. Data bachata hai.
2. preload="metadata" = Sirf duration aur info load karo. Fast hota hai.
3. preload="auto" = Pura audio background me load karo. Turant play hoga.

OUTPUT

3. SVG in HTML

Scalable Vector Graphics. Kitna bhi zoom karo quality kharab nahi hogi.

Method 1: Inline SVG

<svg width="100" height="100"> <circle cx="50" cy="50" r="40" fill="red"/> </svg>

Method 2: IMG Tag se

<img src="logo.svg" alt="Logo">
Important Interview Note: Agar `logo.svg` alag file hai toh us file ke andar sabse upar ye line honi chahiye:
<?xml version="1.0" encoding="UTF-8"?>
Warna browser me error aayega ya image load nahi hogi.

OUTPUT

Ye circle Inline SVG se bana hai

4. <iframe> Tag

Ek website ke andar dusri website embed karne ke liye. Jaise YouTube video, Google Map.

<iframe src="https://youtube.com/embed/VIDEO_ID" width="400" height="225"></iframe>

src = jis page ko embed karna hai
width/height = size
frameborder = border hatane ke liye 0

OUTPUT

Quick Summary

<video>Video + controls, width, height, poster
<audio>Audio + controls. preload interview ke liye
<svg>Scalable graphics. IMG se use karne pe XML header jaruri
<iframe>Bahari website embed
