Step 1: CSS aur JavaScript File ko HTML se Kaise Jodein?

Bhai abhi hum HTML ka skeleton banana seekh rahe hain. Aage ke chapters me hum HTML ke saare tags detail me padhenge jisse ek strong website ka structure banega.

Par usse pehle ye samajhna zaroori hai ki website ko sundar aur smart banane ke liye 2 aur file hoti hain:

  1. CSS = Website ka Makeup Artist. Rang, font, layout sab yehi sambhalta hai.
  2. JavaScript = Website ka Dimaag. Button click, popup, animation sab yehi karta hai.
Important Note: Abhi hum HTML ke tags hi seekh rahe hain. CSS aur JS ko detail me hum HTML khatam karne ke baad padhenge. Aaj hum sirf ye seekhenge ki "bani hui CSS aur JS file ko HTML me kaise jodte hain". Isko bolte hain "Linking". Ye sirf ek demo hai.

Step 2: Folder Structure

Ek hi folder me ye 4 file banao. Naam same rakhna jaruri nahi hai. Ye maine demo ke liye banaya hai.
Aapko keval dhyaan rakhna hai ki CSS file ke last me .css aur JS file ke last me .js lage.


Mera-Project-Folder/
├── index.html          <- Ye wali tutorial file
├── first-website.html  <- Isko hum demo ke liye kholenge
├── style.css           <- CSS file. Last me .css hona chahiye
└── script.js           <- JS file. Last me .js hona chahiye

Step 3: CSS File ko Kaise Link Karein?

CSS file ko jodne ke liye <head> ke andar <link> tag lagate hain.

VS Code me aisa dikhega:

<head>
    <title>Meri Website</title>
    <!-- Ye line CSS ko jodti hai -->
    <link rel="stylesheet" href="style.css">
</head>

Samjho: href="style.css" me `style.css` ki jagah aap apni file ka naam bhi likh sakte ho. Bas last me .css hona chahiye.

Step 4: JavaScript File ko Kaise Link Karein?

JS file ko jodne ke liye <script> tag lagate hain. Isko hamesha <body> ke bilkul end me lagao.

VS Code me aisa dikhega:

<body>
    <h1>Hello World</h1>
    
    <!-- Ye line JS ko jodti hai -->
    <script src="script.js"></script>
</body>

Samjho: src="script.js" me `script.js` ki jagah aap apni file ka naam bhi likh sakte ho. Bas last me .js hona chahiye.
Kyu end me? Taaki pehle website dikhe, phir JS chale. Nahi to website slow lagegi.
