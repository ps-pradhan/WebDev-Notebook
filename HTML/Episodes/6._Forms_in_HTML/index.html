Episode 06: Forms in HTML

Form kya hota hai?

Socho tum dukaan me gaye. Dukaandaar tumse naam, number, address maangta hai. Website bhi wahi kaam karti hai. Form ke through wo tumse data maangti hai.

Eg- sign up/login/help requests/contact me

1. Basic Structure of Form

Saara khel <form> tag ke andar hota hai. Ye ek dabba banata hai jisme saare sawal hote hain. 


<form action="/action.php" method="post">
    <!-- form content -->
</form>

Samjho:
action="/action.php" = Form bharne ke baad data is file me jayega. Jaise chithi postbox me jaati hai
method="post" = Data chhup ke jayega. Password ke liye yehi use karte hain. `get` me data URL me dikh jata hai

2. Input Tag - Form ka Dil

Form me jo bhi box, button dikhta hai wo sab <input> se banta hai. Iska roop `type` se badalta hai.

Basic Syntax

<form action="/action.php">
  <input type="" name="" placeholder="">
</form>

a) Type Attribute

HTML mein <input> tag ke saath type attribute ka istemal yeh batane ke liye kiya jata hai ki user se kis tarah ki jaankari (Data) leni hai. Yeh browser ko batata hai ki input field kaisa dikhega. Jaise, kya user ko apna naam type karna hai ya password dalna hai

Ye Table Kyu Important Hai?

Ye Table Samajhna Kyu Zaroori Hai?

b) Name Attribute

Name Attribute se 2 bade fayde

  1. Data ko pehchanna: Server ko pata chalta hai ki kaunsa data kis field ka hai. `username=Amit`, `email=abc@gmail.com`
  2. Radio ko group karna: Same `name` wale radio button me se sirf 1 hi select ho sakta hai

Rule: Server hamesha data ko `Name = Value` ke roop mein samajhta hai

Example 1: Text Input

<form action="/action.php">
  <input type="text" name="username"  placeholder="Enter your Name">
  <input type="submit" value="Submit">
</form>

Samjhao: Agar user "Amit" likhega to server tak ye jayega
username = Amit

Example 2: Radio Buttons - Group karne ke liye

<form action="/action.php">
  <input type="radio" name="gender" value="Male" >Male
  <input type="radio" name="gender" value="Female">Female
</form>
Male Female

Samjho: Dono ka `name="gender"` same hai isliye sirf 1 hi select hoga
Agar Male select kiya to server tak jayega: gender = male
Agar Female select kiya to server tak jayega: gender = female

Note:Value & jo hamne print karaya hai dono Sync main hona chaiye
Kyunki, Server ko sirf Value dikhti hai & User ko sirf Print .

Example 3: Bina name ke kya hoga?

<form action="/action.php">
  <input type="text" placeholder="Enter your Name">
  <input type="submit" value="Submit">
</form>

Important: Is input me `name` attribute nahi hai.
Chahe user kuch bhi likh de, submit karne par ye data server tak nahi pahuchega. Server ise discard kar dega.

3. Label Tag - Dosti wala Tag

label kaam hai input ko naam dena. Lekin iska sabse bada fayda ye hai: Label par click karoge to bhi input box khud select ho jayega.

Kaise kaam karta hai? Jadoo: for = id

Iske liye 2 cheez same honi chahiye:
1. label for="kuch"
2. input id="kuch"

Note: id kya hoti hai?

id matlab "pehchan patra". Jaise har student ka roll number unique hota hai, waise hi har input ka id unique hona chaiye.

Ek page me 2 input ki id same nahi ho sakti.
Kaam: Label ko input se jodna. Baad me CSS aur JavaScript bhi isi id se input ko pakadte hain.

Example 1: Text / Email - Best Practice

Yaha label hamesha upar aata hai. User pehle padhega "kya bharna hai", fir box me type karega.

<label for="userEmail">Email :</label>
<input type="email" id="userEmail">

Dekh kya hoga: Ab agar tum "Email" wale text par click karoge to cursor apne aap email wale box me chala jayega.

Example 2: Radio Button - Sirf 1 option

Yaha gol button pehle aata hai, aur uska naam turant baad me aata hai.

<form action="/action.php">
  <h5>Select your Class</h5>
   <input type="radio" id="class11" name="class" value="xi">
   <label for="class11">Class XI</label>
   <br>
   <input type="radio" id="class12" name="class" value="xii">
   <label for="class12">Class XII</label>
</form>
Select your Class

Dekh kya hoga: "Class XI" ya "Class XII" text par click karoge tab bhi gol button select ho jayega. Area bada ho gaya.

Example 3: Checkbox - 1 se zyada option

<form action="/action.php">
  <h5>Select your Hobbies</h5>
    <input type="checkbox" id="cricket" name="hobby" value="cricket">
    <label for="cricket">Cricket</label>
    <br>
    <input type="checkbox" id="coding" name="hobby" value="coding">
    <label for="coding">Coding</label>
    <br>
    <input type="checkbox" id="music" name="hobby" value="music">
    <label for="music">Music</label>
    <br>
    <input type="checkbox" id="travel" name="hobby" value="travel">
    <label for="travel">Travel</label>
    </form>
Select your Hobbies



Dekh kya hoga: Checkbox bahut chote hote hain. Label lagane se "Cricket", "Coding" likhe hue par click karne se bhi tick lag jayega. Mobile user ke liye ye life saver hai.

Pro Tip: Senior Developer wali Best Practice

  1. Text/Email jaise input: Label upar aur Input niche rakho.
  2. Radio/Checkbox: Input pehle aur Label baad me rakho.
  3. 2 Golden Rules:
    • Rule A: Label ka text hamesha <label> ... </label> ke beech me hi rahega.
    • Rule B: Input ko label ke andar mat ghusao. Dono ko alag rakho aur for aur id se jodo.

Isse code saaf rehta hai aur baad me CSS se design karna 10x easy ho jata hai.

2 aur bade fayde Label ke:

  1. Accessibility: Blind log screen reader use karte hain (screen reader = computer ki awaaz jo screen ka text padh kar sunati hai). label laga hoga to wo bolega "Email edit box".
  2. Click Area Badi: Radio aur Checkbox ke text par click karne se bhi select ho jayega.

Pro Tip: Screen Reader khud kaise Try karein?

  • Android: Settings > Accessibility > TalkBack ON karo
  • iPhone: Settings > Accessibility > VoiceOver ON karo
  • Windows Laptop: Windows + Ctrl + Enter dabao. Narrator chalu
  • Mac Laptop: Cmd + F5 dabao. VoiceOver chalu

Rule yaad rakhna: label for = input id
Dono ka naam bilkul same hona chahiye. Tabhi dosti chalegi 😄

4. Select Tag - Dropdown List

Jab 50 state ho to 50 radio button nahi banayenge. Dropdown banate hain.

<form action="/action.php">
  <label>Sheher chuno:</label>
  <select name="city">
     <option value="delhi">Delhi</option>
     <option value="mumbai">Mumbai</option>
     <option value="hyd">Hyderabad</option>
  </select>
</form>

5. Textarea Tag - Bada Box

Address, Feedback, Story likhne ke liye. Kitni bhi line likh sakte ho.

<form action="/action.php">
  <textarea name="msg" rows="4" cols="40" placeholder="Yaha likho..."></textarea>
</form>

rows = Kitni line unchi
cols = Kitni line chaudi
