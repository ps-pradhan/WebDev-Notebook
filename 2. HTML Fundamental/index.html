HTML Fundamental

Website ki neev yahi se shuru hoti hai

🧱 HTML Boilerplate Code kya hai?

Socho tumhe naya ghar banana hai. Pehle kya karoge? Foundation daaloge na?

Bilkul waise hi, jab bhi hum nayi HTML file banate hain, toh sabse pehle hume ek basic structure likhna padta hai. Ise hi Boilerplate Code bolte hain. Ye har website ki neev ka template hai.

Bina iske browser ko samajh hi nahi aayega ki tumne kya banaya hai. Chal dekhte hain ye template kaisa dikhta hai 👇 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <!-- Yaha apna saara content aayega  -->
</body>
</html>

⚡ Pro Tip: 1 Second me Boilerplate Likho

Bhai ratne ki zarurat hi nahi hai. Agar tum VS Code use kar rahe ho to ye trick use karo:

Step 1: Nayi file banao → index.html

Step 2: Keyboard pe dabao → Shift + 1

Step 3: Dabao → Enter

Bas! Poora Boilerplate code khud se aa jayega ✨
Isko bolte hain Emmet Abbreviation. VS Code ka sabse bada jaadu.

Yaad rakhna: File ka naam .html se end hona chahiye tabhi ye shortcut kaam karega.
🧠 30 Second me Samjho:
`!DOCTYPE` = Browser ko bolta hai "Bhai ye HTML5 hai, aise padhna"
`html` = Puri website ka dabba
`head` = Website ki settings aur naam. User ko nahi dikhega
`body` = Jo user ko dikhega wo sab yaha likhte hain. Yehi asli content hai
