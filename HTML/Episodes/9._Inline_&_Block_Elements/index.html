🎬 EPISODE 09: BLOCK vs INLINE ELEMENTS

Note: Abhi hum style tag & Inline CSS use kar rahe hain. Future me hum External CSS seekhenge.

Concept: HTML me har tag ya to Block hota hai ya Inline. Layout isi se banta hai.

PART 1: BLOCK ELEMENTS

Block ke 3 Rules:

  • 1. Hamesha nayi line se shuru hote hain
  • 2. Puri width lete hain
  • 3. Width, Height, Margin, Padding sab lagta hai

1. <div> - Generic Container

Use: Page ko sections me baatne ke liye

Code - VS Code Style:

<div style="background-color: lightgreen; padding: 10px;">
  Main ek Div hun
</div>

Output:

Main ek Div hun

2. <p> - Paragraph

Use: Text likhne ke liye. Khud gap de deta hai.

Code:

<p style="background-color: pink;">Ye pehla paragraph hai</p>
<p style="background-color: pink;">Ye dusra paragraph hai</p>

Output:

Ye pehla paragraph hai

Ye dusra paragraph hai - Dekho gap aa gaya

3. <h1> to <h6> - Headings

Use: Heading dene ke liye. SEO ke liye important.

Code:

<h1 style="background-color: yellow;">Main H1 hun</h1>
<h3 style="background-color: yellow;">Main H3 hun</h3>

Output:

Main H1 hun

Main H3 hun

PART 2: INLINE ELEMENTS

Inline ke 3 Rules:

  • 1. Nayi line nahi lete, bagal me chipak jaate hain
  • 2. Sirf content jitni width lete hain
  • 3. Width, Height nahi lagta. Sirf Left-Right margin/padding lagta hai

1. <span> - Generic Inline Container

Use: Text ke kisi hisse ko style karne ke liye

Code:

Ye text <span style="background-color: yellow;">yellow</span> hai

Output:

Ye text yellow hai

2. <a> - Anchor / Link

Use: Link banane ke liye

Code:

<a href="#" style="background-color: lightblue; padding: 5px;">Click Me</a>

Output:

Click Me

3. <img> - Image

Use: Image dikhane ke liye. Exception: Inline hai par width/height manta hai

Code:

<img src="https://via.placeholder.com/80" alt="Demo">

Output:
