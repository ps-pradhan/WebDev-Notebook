  1. Hum koi bhi text editor use kar sakte hain.

2. HTML hota kya hai?

HTML → Hyper Text Markup Language

  • HTML website banane ki bhasha hai. Isse hum websites banate hain
  • Hum HTML tags ka use karke website ka look aur structure banate hain
  • In tags ko samajh kar aur saath me jod kar hum aasani se sundar websites bana sakte hain!

3. Toh CSS aur JavaScript ki kya jarurat hai?

Ek website banane ke liye 3 cheezein chahiye hoti hain:

  1. HTML - Page ka skeleton / structure banata hai - Haddi
  2. CSS - skeleton ko sundar banata hai - Kapde aur makeup
  3. JavaScript - Page me jaan dalta hai - Kaam karwata hai. Jaise button pe click kiya toh kya hoga
