HTML Boilerplate Code kya hai?

Jab bhi hum nayi HTML file banate hain, toh ye basic structure likhna padta hai. Ise hi Boilerplate Code bolte hain. Soch lo ye website ka "template" hai. 

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document</title>
</head>
<body>
    <!-- Yaha apna saara content aayega  -->
</body>
</html>
Samjho aise:
`!DOCTYPE` = Browser ko batata hai ye HTML5 hai
`head` = Website ki settings yaha hoti hain
`body` = Jo user ko dikhega wo sab yaha likhte hain
