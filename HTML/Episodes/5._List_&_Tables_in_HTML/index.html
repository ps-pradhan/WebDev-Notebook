🎬 EPISODE 05: LIST & TABLES IN HTML

Recap: Pichle episode me humne HTML ke "Miscellaneous Tags" seekhe.

Aaj ka Agenda: Website par data ko 2 tareeke se dikhate hain: LIST ke form me aur TABLE ke form me. Ye 2 topic har website ki jaan hain.

SCENE 1: LISTS IN HTML 📋

List ka matlab = Related items ka group. HTML me 3 prakar ki list hoti hain.

1. Unordered List <ul> | Bullets wali List

Concept: Jab items ka order important nahi hai. Jaise Grocery List, Features ki list.

Tags: <ul> = Puri list, <li> = List Item

Basic Syntax:

<ul>
  <li>Pen</li>
  <li>Pencil</li>
  <li>Eraser</li>
</ul>

Output:

  • Pen
  • Pencil
  • Eraser

Bullet Style Customize karna - `type` Attribute

Default = disc. 3 type hote hain:

  • type="disc" = ●
  • type="circle" = ○
  • type="square" = ■
<ul type="square">
  <li>Notebook</li>
  <li>Marker</li>
</ul>

Output:

  • Notebook
  • Marker

Note: Modern HTML me `type` attribute purana ho gaya hai. CSS se style karna best practice hai. Abhi ke liye bas concept samjho.

2. Ordered List <ol> | Number wali List

Concept: Jab sequence ka matlab hai. Jaise Recipe Steps, Top 10 List.

Tags: <ol> = Puri list, <li> = List Item

Basic Syntax:

<ol>
  <li>Mango</li>
  <li>Orange</li>
  <li>Litchi</li>
</ol>

Output:

  1. Mango
  2. Orange
  3. Litchi

Numbering Customize karna

2 important attributes hain:

1. `type` Attribute: Number ka format

  • type="1" = 1, 2, 3 default
  • type="A" = A, B, C
  • type="a" = a, b, c
  • type="I" = I, II, III
  • type="i" = i, ii, iii

2. `start` Attribute: Number kaha se shuru hoga

<ol type="A" start="3">
  <li>Pen</li>
  <li>Pencil</li>
</ol>

Output:

  1. Pen
  2. Pencil

3. Definition List <dl> | Dictionary wali List

Concept: Jab Term aur uska Description dikhana ho. Jaise Glossary, FAQ, Metadata.

Tags: <dl> = Definition List
<dt> = Definition Term / Shabd
<dd> = Definition Description / Matlab

Example:

<dl>
  <dt>HTML</dt>
  <dd>HyperText Markup Language: Webpage ki structure banati hai.</dd>
 
  <dt>CSS</dt>
  <dd>Cascading Style Sheets: Webpage ko design karti hai.</dd>
</dl>

Output:

HTML
HyperText Markup Language: Webpage ki structure banati hai.
CSS
Cascading Style Sheets: Webpage ko design karti hai.

SCENE 2: TABLES IN HTML 📊

Table ka use row aur column me data dikhane ke liye hota hai. Jaise Marksheet, Price List.

Table ke Basic Building Blocks

TagFull FormKaam
<table>TablePuri table ka container
<tr>Table Row1 horizontal line
<th>Table HeadingHeading cell, text mota hota hai
<td>Table DataNormal data cell

Basic Table Example:

<table border="1">
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Harry</td>
    <td>100</td>
  </tr>
</table>

Output:

NameAge
Harry100

TABLE ATTRIBUTES & ADVANCED TAGS

Professional table banane ke liye ye tags bahut kaam aate hain.

1. `<caption>` | Table ka Title

Table ke upar heading dene ke liye. SEO aur Blind logon ke liye bahut important hai.

<table>
  <caption>Student Marks</caption>
</table>

2. `<thead>` `<tbody>` `<tfoot>` | Table ko 3 Part me baatna

Badi table ko manage karna aasan ho jata hai. Browser ko bhi samajh aata hai.

  • thead = Header wale row
  • tbody = Main data wale row
  • tfoot = Last me Total/Summary wale row

3. `colspan` Attribute | Column Merge karna

1 cell ko horizontally kai column jitna bada karne ke liye.

<td colspan="2">Ye 2 Column lega</td>
Merged Columns
Column 1Column 2

4. `rowspan` Attribute | Row Merge karna

1 cell ko vertically kai row jitna bada karne ke liye.

<td rowspan="2">Ye 2 Row lega</td>
Row 1Merged Rows
Row 2

5. `scope` Attribute | Accessibility ke liye

Screen reader ko batata hai ki ye th kis column ya row ka heading hai.

<th scope="col">Name</th> <!-- Ye column ka heading hai -->
<th scope="row">ID</th> <!-- Ye row ka heading hai -->

6. `<colgroup>` `<col>` | Puri Column ko ek saath control karna

Agar 1 puri column ka background color change karna ho to.

<colgroup>
  <col style="background-color:yellow">
</colgroup>

🔥 CLIMAX: FINAL BOSS EXAMPLE 🔥

Ye rahi ek puri professional table jisme sab kuch use hua hai. Interview me yahi poochte hain.

<table border="1">
  <caption>Employee Information</caption>
 
  <thead>
    <tr>
      <th scope="col">ID</th>
      <th scope="col">Name</th>
      <th scope="col">Position</th>
      <th scope="col">Salary</th>
    </tr>
  </thead>
 
  <tbody>
    <tr>
      <td>1</td>
      <td>Alice</td>
      <td>Developer</td>
      <td>$80,000</td>
    </tr>
    <tr>
      <td>2</td>
      <td>Bob</td>
      <td>Designer</td>
      <td>$70,000</td>
    </tr>
  </tbody>
 
  <tfoot>
    <tr>
      <td colspan="3">Total Employees</td>
      <td>2</td>
    </tr>
  </tfoot>
</table>

Output:

Employee Information
IDNamePositionSalary
1AliceDeveloper$80,000
2BobDesigner$70,000
Total Employees2

🎬 POST CREDIT SCENE

Golden Rule: Data dikhane se pehle khud se 1 sawal poocho: "Kya ye data Row-Column me hai?" Haan = table , Nahi = ul/ol/dl

Interview Tip: thead, tbody, tfoot aur scope ka naam lene se interviewer impress ho jata hai.

🏁 THE END
