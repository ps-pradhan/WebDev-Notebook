2. What is HTML?

HTML → Hyper Text Markup Language

  • HTML is the language of the web. It is used to create websites
  • We use HTML tags to define look & feel of a website
  • With understanding of these tags and How to put them together, we can create beautiful websites easily!

3.Then Why we use CSS & JavaScript also ?

Website banane ke liye 3 cheez chahiye:

  1. HTML - defining layout of a page - A barebone page structure
  2. CSS - add styling to that barebone page created using HTML
  3. JavaScript - program logic for the page layout eg. what happens when a user hovers on a text, when to hide or show elements etc.
