🎬 EPISODE 01: WEB DEVELOPMENT KI SHURUAT

⚠️ Pro Tip: Isko ratna mat. Har scene ko samajh ke khud VS Code me likhna. Tabhi developer banoge.

SCENE 1: INTERNET KA RESTAURANT

Kahani: Socho tumne Zomato khola aur Burger order kiya. Tum ho Client. App hai Browser. Aur Zomato ki kitchen hai Server.

Lesson: Internet pe bhi yahi hota hai. Jab tum google.com open karte ho, tum request bhejte ho, Server data deta hai, Browser usko dikhata hai. Bas 3 kirdaar yaad rakh lo.

SCENE 2: HAMARA HATHIYAR - VS CODE

Kahani: Har carpenter ke paas ek best wala hammer hota hai. Developer ka hammer hai VS Code.

  1. Ye free hai. Paisa nahi lagega
  2. Ye halka hai. Purane laptop me bhi chalega
  3. Isme Extensions lagao aur ye Superhero ban jata hai

Note: Shuru me Notepad se bhi kaam chal jayega. Par 2 din baad VS Code install kar lena. Life easy ho jayegi.

SCENE 3: HTML = WEBSITE KI HADDI

Kahani: Agar website ek insaan hai, to HTML uski haddi hai. Bina haddi ke insaan khada nahi ho sakta. Bina HTML ke website nahi banegi.

HTML = Hyper Text Markup Language

  • Isse hum website ka structure banate hain
  • Heading, Para, Image, List - ye sab HTML ke tag hote hain
  • Ye sirf batata hai "ye heading hai, ye para hai". Sundar nahi banata

SCENE 4: 3 STAMBH KA FORMULA

Kahani: Duniya ki har badi website 3 bhai milkar chalate hain. Teenon ka kaam alag hai.

  1. HTML - Haddi. Structure deta hai. Ye hum Season 1 me seekhenge
  2. CSS - Kapde. Design deta hai. Ye Season 2 me
  3. JavaScript - Dimaag. Kaam karwata hai. Ye Season 3 me

Abhi hum sirf pehle bhai se dosti karenge.

🎉 SAABASH! EPISODE 1 CLEAR 🎉

Level Up: Engine samajh aa gaya. HTML = Haddi, CSS = Kapde, JS = Dimaag 💪
